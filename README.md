# Full Stack Quest: Minha Jornada

Olá! Sou Gilvan Pedro de Castro Melo Campos, estudante de Engenharia de Software no SENAI Goiás. Este repositório guarda os projetos, códigos e anotações da minha evolução para me tornar um Engenheiro Full Stack.

O caminho que estou seguindo é guiado pelo documento **"Full Stack Quest - 3ª Edição: Do Java Zero ao Full Stack"**[cite: 1]. Toda a trilha está organizada de forma progressiva: são 14 Mundos divididos em 44 Fases, culminando na publicação de um sistema completo em produção[cite: 1].

No fim de cada Mundo, enfrentarei uma "Boss Fight", que consiste em um projeto prático projetado para fixar o conhecimento estudado[cite: 1].

* **Personagem:** Desenvolvedor(a) Full Stack Java[cite: 1]
* **Nível atual:** Nível 1 (Aprendiz)[cite: 1]
